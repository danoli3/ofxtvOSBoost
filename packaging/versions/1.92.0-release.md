# Boost 1.92.0 for tvOS

C++20 and the existing tvOS 9.0 deployment target are retained. The official
archive SHA-256 is `5c1d40cb8e19adbf740a4ec2da35b3e58f3f5804b1dce44deb53df72193cbc6c`.

The official release notes and archive build files were inspected. No new
accepted library is listed. Container adds hub; concurrent and non-concurrent
flat-container range changes belong to Unordered. Separate named regression
results cover hub, both flat range APIs, Decimal decomposition, Lockfree bounded
ticket queue, and System void unwrap. The complete reference suite is retained.

Legacy tvOS chrono, date_time, filesystem, graph, random, and thread are retained.
Regex and System now provide header-only APIs; Signals was removed upstream and
Signals2 is included. The manifest also selects the modern reference compiled
libraries, subject to the validation record. Cobalt's optional IO/TLS archives
are not selected. Redis uses its upstream separate-compilation headers, with
only offline tests; no Redis archive is claimed. All upstream headers ship.

Apple SDK paths, compiler targets, XCFramework slice identifiers, UIKit app
settings, CocoaPods, SwiftPM and CMake all target tvOS. B2 uses `target-os=iphone`
for the Apple embedded OS family; explicit AppleTV SDKs and target triples
must determine the actual Mach-O tvOS platform.

Upstream release: https://www.boost.org/releases/1.92.0/
